# Reference

The reference lists everything jolty offers, as the code defines it.

- [Command line](cli.md): every command and option, generated from the request models the MCP server shares.
- [Rules](rules.md): every rule of the structural checks, its default level and its exact condition.
- [Configuration](configuration.md): every setting, generated from the settings model.
- [Expressions](expressions.md): the language of behavioral sources, from the engine's parser.
- [Models](models.md): every device model and its parameters, with their defaults and descriptions, from the engine.
- Python API: [circuits](circuits.md), from units, devices and SPICE models to the builder and the circuit format, [simulation](simulation.md), from plans to results and their files, and [images](images.md), schematics and plots.
